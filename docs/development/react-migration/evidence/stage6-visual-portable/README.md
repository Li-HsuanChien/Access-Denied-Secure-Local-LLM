# Post-cleanup parity tools

Executed temporary sources are retained beside each evidence directory; these portable copies change only repository discovery, preview port and output directory wiring. They do not modify application or accepted captures. Run from the repository root with Python/Pillow and the installed Playwright full Chromium. Every service request is intercepted by fixtures. Never point the original role at a newly React-backed5173 server.

```sh
python3 capture-once.py http://127.0.0.1:4177 /private/tmp/unique-capture /private/tmp/unique-run
PARITY_OUTPUT_DIR=/private/tmp/unique-menus PARITY_PORT=4177 node menus.mjs
PARITY_OUTPUT_DIR=/private/tmp/unique-pinned PARITY_PORT=4177 node pinned.mjs
PARITY_OUTPUT_DIR=/private/tmp/unique-assets PARITY_PORT=4177 node assets.mjs
```

PARITY_REPO_ROOT may explicitly select a repository directory. These candidate-only probes never open5173 or5174. Preserve failed runs. The capture wrapper never retries or relaxes the independent repeat assertion.
