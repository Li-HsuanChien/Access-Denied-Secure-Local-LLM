## Additional one-job violation

**B16 · high — Send now overlaps local requests.** With a3500ms delayed first answer, queue a second question and click Send now. Recorded request timeline:

| Question | Start (epoch ms) | Settled (epoch ms) |
| --- | ---: | ---: |
| first delayed |1792519347034 |1792519350535 |
| second queued |1792519347843 |1792519351345 |

The second request starts809ms after the first and2692ms before it settles. Ordinary queue completion is sequential, but Send now uses cosmetic Stop then dispatches. Real host may return busy, rather than executing two jobs; the frontend must preserve real serialization and truthful non-cancellation. Approved safety exception: omit cosmetic Stop and overlapping Send now dispatch, preserve ordinary serialization plus queue Edit/Delete, and do not invent cancellation. Original captures must retain original controls.

## Known limitations that are not new defects

- `/status` shows a dispatch-time context estimate rather than measured model usage. The original single-answer probe retained `9 tokens` after completion and displayed Chat ID `temporary:undefined`. Preserve the original calculation/timing and label; these are not a backend token-metering or durable conversation interface.
- Local answering returns a complete result and has no cancellation transport. Browser-observed Stop ends visible loading immediately, but the original answer still arrives and is saved. A queued second question executes after the first. The backend remains the one-job authority.
- History contains individual saved answers, not a persisted Open WebUI branch graph. History Delete is immediate; Clear all uses browser `confirm('Delete all saved conversations from this computer?')`.
- The product supports Tauri; the loopback browser is developer QA. This inventory does not certify a browser deployment, real model quality, packaged runtime, reference-machine latency, or cross-platform release behavior.
- Audio/video and vendor-specific tool-output tokens were not individually qualified. Vega/Vega-Lite inline charts, inert HTML/SVG preview controls, colon fences/alerts and multiline collapsible details were checked separately and are reachable. Their unverified status is an explicit coverage boundary, not an instruction to add them.

## Model-row menu follow-up

Stage 5 actual interaction exposed the model row's hover-only More Options button. Its Keep/Hide in Sidebar actions immediately update the original local settings store, adding/removing the Models → Document Assistant row, then call the same unsupported upstream settings endpoint described in B11. The request fails; the visible local state has already changed. Reload loses the pin. React preserves the local toggle and sidebar appearance without that unsupported request or invented pin persistence. Copy Link copies the local `/?model=secure-qa-local` URL and closes the submenu; the original renders no success toast. These actions were omitted from the initial inventory and are included in the corrective parity checks.
