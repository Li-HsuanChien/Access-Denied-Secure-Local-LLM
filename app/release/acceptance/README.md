# Packaged offline acceptance tests

Scaffold only. Reserved for network-disabled first-launch and full-flow tests on Windows x86-64, macOS Apple silicon, and Ubuntu Linux x86-64. These tests verify Open WebUI host startup, import, answering, citations, history, release checks, absence of non-loopback listeners, and absence of DNS or outbound connection attempts. See the [SDD release requirements](../../../docs/architecture/SDD.md).
