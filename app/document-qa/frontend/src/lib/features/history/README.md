# History frontend

`HistoryPage` and `HistoryClient` list and open local answer snapshots. The page filters saved chats client-side over the titles and any loaded content the History interface already returns (no host search operation), previews a selected chat with its single basis label and sources, offers Continue this chat (`/conversation/:id`), and deletes one chat after a confirm dialog. Clearing all history and the persistence switch live in Settings; when history is off the page links there. The React chat saves best-effort and leaves the current answer visible if saving fails. See the [Conversation History design](../../../../../../../docs/architecture/SDD.md#43-conversation-history).
