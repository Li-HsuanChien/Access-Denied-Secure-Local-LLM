# Frontend features

User-facing behavior is grouped here by workflow: Library, Answering, History, and Settings, plus the shared `personality/` copy and styles. `workflowTransport.ts` is the single loopback request function the Library, History, and Settings clients use. React feature views call the Python workflow interfaces through the local host; evidence classification, publication safety, and persistence rules stay in the owning workflow modules. See the [SDD](../../../../../../docs/architecture/SDD.md) and [React contracts](../../../../../../docs/development/react-migration/react-contracts.md).
