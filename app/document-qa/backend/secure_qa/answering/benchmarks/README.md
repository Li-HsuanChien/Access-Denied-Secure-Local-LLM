# Question Answering benchmarks

This feature holds answer correctness, grounding, citation, refusal, visual-question, model latency, and token-rate evaluation material. The SDD defines model eligibility and release gates. Retrieval benchmarks belong to Collection Library; whole-process memory checks belong to the desktop shell.

The llama.cpp adapter includes runtime baseline and quantization benchmark tooling under [`../llama_cpp/`](../llama_cpp/README.md). These prototype results do not qualify a final model on the reference laptop; see the [E1 runtime report](../../../../../../docs/reports/E1-runtime-report.md).
