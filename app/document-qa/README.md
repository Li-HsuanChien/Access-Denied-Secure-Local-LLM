# Document-QA application

This is the core application runtime area, not one workflow module. It contains the analyst-facing React frontend (`frontend/`) and Python host/workflow modules (`backend/`). Product-specific frontend features live under `frontend/src/lib/features/`; the five workflow modules live under `backend/secure_qa/`. The developer host currently uses Python `ThreadingHTTPServer`; FastAPI hosting and the Tauri production boundary remain design targets. To run locally, follow the [frontend README](frontend/README.md). Keep workflow rules behind their public interfaces: frontend code calls workflow interfaces and does not own publication, evidence, citation, or persistence invariants. See the [PRD](../../docs/product/PRD.md), [SDD](../../docs/architecture/SDD.md), and [ADR 0004](../../docs/architecture/decisions/0004-react-frontend-parity.md).
