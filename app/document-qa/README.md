# Document-QA application

This is the core application runtime area, not one workflow module. It contains the analyst-facing frontend (`frontend/`) and the Python host/workflow modules (`backend/`). It uses a pinned Open WebUI fork for the Svelte frontend and Python host inside the Tauri desktop application. Product-specific frontend features live under `frontend/src/lib/features/`; the four workflow modules live under `backend/secure_qa/`. Keep workflow rules behind their public interfaces and use Open WebUI as an internal implementation, not as owner of publication, evidence, citation, or persistence invariants. See the [PRD](../../docs/product/PRD.md), [SDD](../../docs/architecture/SDD.md), and [ADR 0001](../../docs/architecture/decisions/0001-open-webui-offline.md).
