# Application layout

This directory holds one desktop product. It groups the [Tauri shell](desktop/README.md), the [React frontend and Python workflows](document-qa/README.md), and [release assembly](release/README.md). The Tauri shell and release assembly remain scaffolds; the document-QA frontend and backend are implemented. The five workflow modules live under `document-qa/backend/secure_qa/`; React frontend code lives under `document-qa/frontend/src/`. Product behavior belongs to the workflow modules rather than frontend components. The [PRD](../docs/product/PRD.md) and [SDD](../docs/architecture/SDD.md) define product behavior and architecture.
