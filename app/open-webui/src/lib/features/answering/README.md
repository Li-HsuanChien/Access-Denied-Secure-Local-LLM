# Answering frontend

Scaffold only. This feature will show the current question, structured answer sections, warnings, and expandable cited pages. It will render evidence classifications returned by Question Answering rather than infer them from model text. See the [Question Answering design](../../../../../../docs/superpowers/specs/2026-09-22-secure-local-document-qa-codebase-design.md#42-question-answering).
