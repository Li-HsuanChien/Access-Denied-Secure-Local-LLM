# Settings frontend

Scaffold only. This feature will expose only user choices permitted by the SDD, including general-knowledge and history-persistence settings. It will not expose remote model connections, web search, plugins, autonomous tools, or runtime downloads. See the [offline controls](../../../../../../docs/superpowers/specs/2026-09-22-secure-local-document-qa-codebase-design.md#6-offline-and-capability-controls).
