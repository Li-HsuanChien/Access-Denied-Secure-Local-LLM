# Frontend features

Scaffold only. User-facing behavior is grouped here by workflow: Library, Answering, History, and Settings. SvelteKit routes and reused Open WebUI views should call these feature modules through small interfaces. Evidence classification, publication safety, and persistence rules remain in the Python workflow modules.
