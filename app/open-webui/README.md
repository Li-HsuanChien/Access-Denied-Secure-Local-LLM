# Open WebUI source fork

Scaffold only. A reviewed, pinned Open WebUI fork will live here during implementation. Its existing `src/` tree is the SvelteKit frontend; `backend/` is the Python host. The feature folders below reserve locations for new product behavior while preserving upstream paths. No upstream source, dependencies, or built assets have been downloaded.
